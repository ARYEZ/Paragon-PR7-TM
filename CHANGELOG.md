# Changelog

## 0.1.0

- First release: a terminal, the way Windows Terminal and PuTTY work.
- Tabs and split panes with Windows Terminal's keys; this PC's shells (PowerShell, Command Prompt, WSL, Git Bash)
  through ConPTY; an administrator window on request.
- SSH with saved sessions: key file, password or agent, keep-alive, a command after connecting, port forwarding;
  host keys checked before signing in; passwords in Windows' Credential Manager; Quick connect.
- Selection, copy and paste (bracketed), scrollback, Find, font size; R restarts an ended pane.
- Terminal colours in the family's hues; OBSIDIAN and AURORA finishes; Check for Updates.
